# ABC 重分类(按仓库任务频率)

本 skill 把「最近 N 个月仓库任务 → 按物料统计频次 → 重划 ABC 标识」做成一条可重复执行的流程。时间窗与占比均由用户决定;**修改主数据属写操作,必须先获用户授权**。

## 输入参数(执行前向用户确认)

| 参数 | 默认值 | 说明 |
|---|---|---|
| 时间窗 | 最近 3 个月 | WT 创建日期范围 `CREATED_AT >= YYYYMMDD000000` |
| A 占比 | 10% | 按频次降序排名的前 X% |
| B 占比 | 30% | 次之的 Y% |
| C 占比 | 60% | 其余 |
| 仓库号 lgnum | `CN01`(已知实例,仍须确认) | WT 查询必填 |
| 取消任务 | 排除(`tostat <> 'A'`) | 用户可要求计入 |
| 工序类型 | 不限 | 可按 `PROCTY` 收窄 |

占比三项之和须等于 100%,否则先纠正再执行。

## 流程总览

1. 读 WT → 2. 按物料聚合 → 3. 解析 MATID→物料号 → 4. 排名分层 → 5. 出对照表请授权 → 6. 授权后经 abaper 更新主数据 → 7. 验证回读。

---

## 1. 读取仓库任务

遵循 `sap-ewm` skill 的全部规则(表验证、where/fields 大小写、空结果验证法)。双表配方:

```
table: /scwm/ordim_o   (open)
table: /scwm/ordim_c   (confirmed)
where: LGNUM = '<lgnum>' AND CREATED_AT >= <start>000000 AND CREATED_AT <= <end>235959
fields: TANUM, MATID, CREATED_AT, TOSTAT, PROCTY
```

- 一条 WT 只在两表之一,**两表都要查**后合并。
- 排除已取消时过滤 `TOSTAT <> 'A'`。
- WT 表**没有 `matnr`**,物料以 `matid`(GUID)标识——这正是第 3 步要解决的问题。
- 3 个月数据量可能较大:若单次取数受限,按月(或按周)分片查询后在本地聚合。

## 2. 按物料聚合

合并两表结果,按 `MATID` 计数(默认排除已取消),得到 `MATID → WT 数` 列表。聚合时须核对总行数与原始取数行数一致,防止分片遗漏。

## 3. 解析 MATID → 物料号

🔴 **禁止臆测解析路径。** `matid` 是 GUID,物料号解析须先经 MCP 实测确定一条可行路径(候选方向:含 GUID 与物料号双列的对照表 / 产品主数据视图,以 `GetTable`/`SearchObject` 核实存在后再用)。解析方法确定后:

- 抽 3~5 个 `MATID` 用该路径验证解析结果合理性(物料号非空、格式正确)。
- 有 `MATID` 解析不出物料号的,列入例外清单报告用户,**不得丢弃了事**。

## 4. 排名与分层

1. 按 WT 数降序排序(同数量者按物料号排序,保证结果可复现)。
2. 切分规则:第 `⌈物料总数 × A占比⌉` 名及以前 → **A**;再往下 `⌈物料总数 × B占比⌉` 名 → **B**;其余 → **C**。
3. ⚠️ 若切分线上存在同数量的物料被划入不同档,向用户说明并给出两种处理(严格按占比切分 / 同数量同档,占比略有偏移),由用户定夺。
4. WT 数为 0 的物料不在本次统计范围内(它们不在 WT 里),默认不动其 ABC 标识,在报告中注明。

## 5. 输出对照表 + 请授权

产出(存 `workfolder/`):

- **ABC 对照表 CSV**:物料号、WT 数、排名、现 ABC 标识、拟 ABC 标识。
- **变更摘要**:A/B/C 各档物料数、实际占比、与目标占比的偏差。

现 ABC 标识的读取:ABC 标识预期在物料主数据的工厂级字段(如 MARC 的 ABC 标识字段),**字段名须先用 `GetTable`/`GetStructure` 实测确认**,再经 `GetTableContents` 批量读取现值。

随后由主 Claude 向用户汇总请授权。**未获授权时到此为止**,只交付对照表与变更摘要。

## 6. 更新主数据(须用户授权)

MCP 无业务数据写工具,更新物料主数据 ABC 标识的实际落法是 ABAP 代码(如经标准 BAPI 更新物料主数据;具体 BAPI 名与字段映射须实测确认)。获授权后:

1. 主 Claude 派 `abaper`,prompt 中标注「已授权可执行」。
2. `abaper` 遵循 `abap-adt-write` skill 创建/修改/激活代码;ABC 档清单作为输入数据(硬编码表 / 参数文件,由 abaper 定,方案报用户确认)。
3. 代码创建前先由主 Claude 报用户授权本次具体对象与方案。

## 7. 验证

派 `tester` 按 `abap-test-verify` skill 验证:读回抽样物料的 ABC 标识确认与对照表一致;代码侧确认激活无错。

## 约束

- 第 1~5 步**只读**,任何情况下可直接执行。
- 第 6 步起为写操作,**未获用户授权严禁执行**;agent 不得以任何理由(便于测试/临时验证等)越权。
- 断言任何表名/字段名/BAPI 名前,先经 MCP 实测确认;禁止列出多个候选逐一尝试。
- 所有产出文件存 `workfolder/`。
